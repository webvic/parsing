# parsing
Парсинг данных с сайта через Тг бота
Загружаем актуальный список метро с ЦИАН (500+)

вводим 2 параметра 
- к-во комнат
- часть имени метро
-- выбираем из тех метро что сматчились одно
Выдаем аналитику по найденным квартирам
Обрабатываем блокировку по большому-к-ву запросов - выдаем все что нашлось до блокировки 10-17 страниц
